# Neutral

Neutral is an open-source programming language and developer ecosystem for
tooling, automation, CI/CD, infrastructure, and system workflows.

The **Neutral programming language** is the central project. The wider
ecosystem is intended to provide a coherent set of modular tools that can also
be used independently.

## Projects

- **Neutral** — the programming language and toolchain
- **Neutral CLI** — a unified developer interface for the ecosystem
- **Neutral CI/CD** — experimental, provider-neutral pipeline tooling
- **Neux** — standalone Linux system tooling

Repository names and scopes may evolve while the ecosystem takes shape. Links
will be added as project repositories become public.

## Principles

- **Open source:** development is open to inspection and contribution.
- **Provider neutral:** tools should avoid unnecessary platform lock-in.
- **Modular:** projects should remain independently useful.
- **Developer focused:** interfaces should be understandable and scriptable.

## Status

Neutral is in early development. Language syntax, APIs, tooling, and repository
structure may change. No project listed here should be assumed production-ready
unless its own repository says otherwise.

Follow development in the [Neutral Ecosystem organization](https://github.com/neutral-ecosystem),
read the [roadmap](https://github.com/neutral-ecosystem/.github/blob/main/ROADMAP.md),
or review the [contribution guide](https://github.com/neutral-ecosystem/.github/blob/main/CONTRIBUTING.md).
